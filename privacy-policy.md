# Privacy Policy

Big Text Viewer is an offline desktop text viewer.

The program does not automatically collect, transmit, upload, or share
personal information, file contents, search keywords, usage statistics,
or device information.

The program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or
operating it.

Files selected by the user are processed locally on the user's computer.
